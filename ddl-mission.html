01 / 实际问题

任务不缺记录工具，缺的是不被遗忘

课程作业、实习周报和生活事项分散在不同地方。手动记录之后还要反复检查，临近截止时才意识到遗漏，时间管理的成本反而更高。

02 / 我的职责

从交互和视觉，做到同步与系统通知

我完成单文件网页应用、自然语言解析、倒计时与主题系统，并补上 Python 本地同步服务器、macOS 桌面小组件和原生通知。

03 / 解决流程

减少创建和检查任务的每一步阻力

  • 用自然语言输入任务，识别时间、循环周期、分类和优先级。
  • 用秒级倒计时和日食环呈现最紧急任务的时间流逝。
  • 通过本地服务器、桌面小组件和局域网设备同步，并在关键时间主动提醒。
04 / 技术实现

轻量，但功能完整

  • 原生 HTML/CSS/JS：零依赖、零构建，单文件即可离线运行。
  • Canvas + Bayer 抖动：绘制像素月球与倒计时环。
  • Python 标准库服务器：负责任务与主题同步、JSON 存储和通知值守。
  • localStorage + Übersicht：兼顾浏览器降级存储和 macOS 桌面体验。
05 / 成果数据

从“记下来”到“自动跟进”

四套主题覆盖像素、工程、奶油与极简；任务和主题可在五秒内同步；T-24h、T-1h 和逾期三档通知，即使浏览器关闭也能收到。
