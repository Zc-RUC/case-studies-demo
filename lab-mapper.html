01 / 实际问题

信息分散，人工 Mapping 难以规模化

学生信息散落在实验室、导师、个人主页、CV 和 Scholar 页面。面对数百名候选人，逐项查找、复制和核验不仅耗时，也容易出现毕业时间与身份误判。

02 / 我的职责

把业务规则整理成可复用的 Agent 工作流

我负责配置 Codex Skill，定义输入输出、来源优先级、毕业年份推断、候选人判断与质量检查规则，并将它应用到 27 届实验室 Mapping 中。

03 / 解决流程

先核验，再结构化，再判断

  • 从官方实验室、导师和成员页面开始，跟踪个人主页与公开资料。
  • 补全研究方向、联系方式、主页与经历，保守推断入学和毕业时间。
  • 输出 YES / MAYBE / NO 判断，同时保留证据 URL 和置信度。
04 / 技术实现

不仅是“自动搜集”，更是可复核的规则

  • Codex + Agent Workflow：将链接解析、资料补全和表格输出串成可复用流程。
  • 16 个字段：覆盖学位、导师、实验室、时间、研究方向、证据与判断。
  • 质量检查：不猜测邮箱，不随意合并同名候选人；未知字段明确写 Unknown，并标注置信度。
05 / 成果数据

从重复劳动到批量交付

累计完成 500+ 名相关实验室硕博毕业生 Mapping，较上一届全人工流程提速数倍。每行保留证据，便于团队复核与后续跟进。
